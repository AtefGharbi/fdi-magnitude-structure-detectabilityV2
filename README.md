# fdi-magnitude-structure-detectabilityV2 — code and per-seed results (release v2.1)

Code and per-seed results for:

A. Gharbi, A. Alshammari, H. A. Alanazi, N. Ben Halima and D. Ben Noureddine,
*Frontiers in Neuroscience* (revised manuscript, R2).

All results in the article, including the motivating example (Section 4.1, Figure 3), were produced with this release
(tag `v2.1`). Earlier exploratory code is in
[fdi-magnitude-structure-detectabilityV1](https://github.com/AtefGharbi/fdi-magnitude-structure-detectabilityV1).

## Files

| File | Purpose |
|---|---|
| `common.py` | Data generation (same RNG order as the original scripts; network built once per process for speed). Includes the original H1 constructions, the previous factorial generator, and the clean operating-point bank used by the corrected design. |
| `detectors.py` | Random Forest, published physics-informed detector (`train_pi`, with diagnostic variants), diagonal-precision and full-precision (Ledoit–Wolf Gaussian likelihood-ratio) readouts. |
| `structcheck.py` | Shows the previous factorial "independent" and "correlated" conditions are identical in distribution (Supplementary Note S1). |
| `run_v2.py` | Corrected controlled experiment (`main`, 20 seeds), channel-count sweep (`ksweep`, 8 seeds), and dispatch of detector diagnostics. Run `python3 run_v2.py` (2 worker processes). |
| `run_all.py` | Motivating example and physics-informed detector diagnostics (`diag`, 8 seeds per system). |
| `theory.py` | Exact ideal-observer AUC versus ρ, k and SNR (isotropic noise); writes `theory.json`. |
| `kdump.py` | Learned vs. least-squares susceptances for seed 0 (Figure 7a); writes `kdump.json`. |
| `analyze.py` | Statistics: Wilcoxon, 95% CI, d_z, JZS Bayes factor, TOST (±0.02 AUC); writes `analysis.json`. |
| `fig3.py` | Figure 3 (motivating example) from `results/diag_*.json`. |
| `figs_new.py` | Figures 4–7 from `analysis.json`, `theory.json` and `kdump.json`. |
| `validate_manipulation.py` | Empirical validation of the correlation manipulation (Supplementary Note S2, Table S8): marginals, off-diagonal correlations, covariance eigenvalues, empirical vs. theoretical participation ratio, separability; `--e2e` adds the end-to-end check on real power-flow data. Writes `validation.json`. |
| `fig_validation.py` | Supplementary Figure S4 from `validation.json`. |
| `results_v2/` | Per-seed JSON: `main_<system>_s<seed>.json` (controlled experiment, 20 seeds × 2 systems) and `ksweep_<system>_s<seed>.json` (channel-count sweep, 8 seeds × 2 systems). |
| `results/` | Per-seed JSON: `diag_<system>_s<seed>.json` (motivating example + detector diagnostics, 8 seeds × 2 systems); `fac_*` are outputs of the previous, superseded factorial design (kept for reference, not used in the article). |
| `figures/` | Article figures as produced by the scripts above. |

## Corrected design

For each system/seed/k, a fixed channel set S and sign pattern u are shared by all conditions; deviation on S is
`t * (sqrt(1-rho) * z + sqrt(rho) * c * u)`, so every affected channel is N(0, t^2) in every condition and only cross-channel correlation differs.
Each condition is a separate binary task against the same 1,200 normal samples.

## Reproduce

Paths are relative to this folder (the generated `data/` cache can be moved with `FDI_DATA`).

```
pip install -r requirements.txt
python3 run_v2.py                       # all per-seed results (results_v2/, results/)
python3 analyze.py                      # statistics -> analysis.json
python3 theory.py                       # ideal observer -> theory.json
python3 kdump.py                        # learned vs. LS susceptances -> kdump.json
python3 fig3.py                         # Figure 3
python3 figs_new.py                     # Figures 4-7 -> figures/
python3 validate_manipulation.py --e2e  # Note S2 / Table S8 -> validation.json (~3 min)
python3 fig_validation.py               # Supplementary Figure S4
```

`analyze.py` reproduces the committed `analysis.json` exactly from the committed per-seed files.

Requirements (versions used): Python 3.12, pandapower, numba, numpy 2.x, scipy 1.x, scikit-learn 1.x, torch, matplotlib, pandas.
